Privacy Policy

Last Updated: 1st July 2026

Clanker respects your privacy. This policy explains what data is stored, how it is used, and how analytics are handled.

What We Store

  • Server IDs
  • User IDs
  • Channel IDs
  • Bot-related data such as balances, settings and statistics

We do not collect personal information such as real names, passwords, or private messages.

How Data Is Used

Data is used only for bot functionality including commands, economy systems, server configuration, and statistics.

Website Analytics

We use Google Analytics to understand how users interact with our website. This may include information such as page views, session duration, device type, browser type, and general usage patterns.

Google Analytics may use cookies and similar technologies. This information is used to understand website usage and improve the Clanker website.

You can view Google's privacy policy here: Google Privacy Policy

Clanker Telemetry

Clanker collects limited telemetry to monitor the bot's performance, reliability, and general usage.

This telemetry may include:

  • The number of servers Clanker is currently in
  • The combined member count across those servers
  • The number of users currently interacting with Clanker
  • Peak concurrent usage since the bot was started
  • The number of commands used since the bot was started
  • Recent command usage rates
  • The approximate time the most recent command was used
  • Bot uptime and telemetry update timestamps

Clanker may temporarily store Discord user IDs in memory while calculating concurrent usage statistics. These IDs are not included in the publicly accessible telemetry data and are removed from the active-user tracker after a period of inactivity.

Aggregate telemetry is published through Clanker's public statistics API and may therefore be accessible to anyone. The telemetry API does not intentionally publish individual Discord user IDs or individual user activity.

Telemetry is used to monitor Clanker's performance, understand general usage, identify problems, and improve the service.

Data Sharing

We do not sell, rent, or share your data with third parties except where required by law.

Data Removal

You can request deletion of your data by:

  • Removing Clanker from your Discord server
  • Contacting support through our Discord server
  • Using /forgetme if available
